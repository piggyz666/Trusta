# 虚拟银行补充业务（2026-10-26）

保持队友版本 UI、签名执行器、独立验账、访问控制与强验证。所有资金均为虚拟资金，未新增真实银行、支付或付费模型调用。生活、机票等业务继续跳转官方网站。

| 入口 | 可办理事项 | 规则与边界 |
| --- | --- | --- |
| /bank/deposits | 开立存单、提前整笔支取、到期支取、本金续存 | 虚拟年利率：90 天 0.80%、180 天 1.00%、365 天 1.30%；提前支取按实际整天、0.20%；利息不足一分舍去；到期后不继续计息；本金续存时利息回原卡，无自动续存。100 元起。 |
| /bank/gold-savings | 每周/每月计划、逐期核对买入、暂停、恢复、取消 | 每期 10～10,000 元，1～12 期；短月取月末，后续仍按原日锚定。到期只提醒，不自动扣款；暂停使旧报价失效。同一期只允许一笔成功交易，实际金额不超过预算。报价必须新鲜，需 R3 适当性及原强验证。 |
| /bank/exchange | 购入/卖出 USD、EUR、HKD、JPY，卡片关联外币钱包 | 默认公开新鲜参考汇率，不可用时不回退。用户可以明确选择内置练习汇率，确认卡与记录标示非市场价。JPY 参考价按每 100 日元归一。报价 120 秒、虚拟手续费 0、保留强验证；成本按比例结转。 |
| /bank/membership | 资产观察、等级、积分明细、兑换、使用及取消虚拟权益 | 用户启用后，服务运行时每日首次采样净资产成本，缺失日期不补记。满 30 天日均 1 万金卡、5 万白金；等级只用于站内展示。启用后净虚拟消费每元一分，退款扣回；不对转账、存款、黄金、换汇或融资费用发积分。积分可以因退款为负，补足后才可用。每种权益每人兑换一次；未用可退积分，已用不能退。权益不抵扣真实商户费用。 |
| /bank/support | 关联交易、提交问题、补充信息、查看人工回复、关闭 | 使用原 chat_handoffs 与 operator 权限。用户只能关联本人记录；无在线值守保证。客服不能批准资金交易。关闭不删除交易或审计记录。 |

资金流程均为：服务端草稿 → 原策略与风险校验 → 用户确认（必要时强验证）→ 签名执行与独立验账 → 余额、持仓、流水和回执同步。新动作参与原冷静期保护。报价与账户变动会使旧确认失效。重复提议不得产生重复成交。

资产总览计入未支取定期本金及外币持仓成本；资产划转不重复算消费。黄金定投最终使用既有 GOLD_BUY 流程。

助手可打开上述页面；这五项新增表单不会被描述成已完成交易。目前未启用 DeepSeek，不把导航或规则助手声称为大模型自动办理。后续接入模型仍须保持独立确认边界。

验收：tests/test_extensions.py 覆盖完整资金闭环、余额不足、到期/提前利息、重复执行、积分退款扣回、资产守恒、跨用户隔离、强验证、定投暂停旧授权失效、HTTP 访问控制、人工回复与定时采样。脚本模型和隔离临时库不产生模型费用。

公网验收脚本 scripts/online_extensions_smoke.py 检查实际域名与隧道接口、五个页面路由、草稿与拒绝、定投暂停/取消、积分报价拒绝、交易工单补充与关闭。不会在线确认资金操作；测试配对设备最后撤销。保留测试草稿、取消计划与已关闭工单审计。执行日志与发布版本见 DEPLOYMENT-HANDOFF.md。

内置浏览器自动化当前无法初始化，因此手机及桌面 UI 实际目视验证仍未完成；构建、响应式样式与页面资源检查不能代替该验证。
