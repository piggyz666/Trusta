# 飞书接入

把 TRUSTA 接成飞书机器人后，可以在飞书里和它对话。默认使用**长连接**：TRUSTA 主动连到飞书，不需要公网地址。

## 1. 在飞书开放平台创建应用

1. 创建**企业自建应用**，添加**机器人**能力。
2. **权限管理**：开通下表两项权限。
3. **事件与回调 → 事件配置**：订阅方式选**使用长连接接收事件**，添加事件 `im.message.receive_v1`。
4. **事件与回调 → 回调配置**：订阅方式选**使用长连接接收回调**，添加卡片回调 `card.action.trigger`。
5. **版本管理与发布**：可用范围要包含会使用机器人的人，然后发布版本。权限和事件在**发布后才生效**，以后改了权限也要重新发布。
6. **凭证与基础信息**：复制 **App ID**（以 `cli_` 开头）和 **App Secret**。

| 权限 | 名称 | 用途 |
| --- | --- | --- |
| `im:message.p2p_msg:readonly` | 读取用户发给机器人的单聊消息 | 收消息 |
| `im:message:send_as_bot` | 以应用的身份发消息 | 回消息、发确认卡片 |

> 漏开权限是最常见的问题：机器人能连上，但收不到消息或回复不出来。

## 2. 填进 TRUSTA

两种方式，结果一样，凭据都只保存在本机 `.env` 里：

- **网页**：打开 **设置 → 飞书**，填 App ID、App Secret，连接方式选“长连接”，点“保存并检测”。TRUSTA 会立刻用这组凭据向飞书换取访问令牌，告诉你凭据对不对。
- **配置向导**：运行 `python -m scripts.setup`，在“接入飞书机器人？”一步选 `y`，按提示填写。

长连接需要飞书官方 SDK（Windows 便携版已自带）：

```bash
pip install -r requirements-channels.txt
```

填好后**重启 TRUSTA**。飞书连接在启动时建立，窗口里会显示“飞书长连接已启动”，日志在 `data/feishu-worker.log`。凭据只能在运行 TRUSTA 的那台电脑上修改，配对的手机只能查看。

## 3. 绑定你的账户

飞书用户必须先绑定，才能以你的身份使用 TRUSTA：

在 **设置 → 飞书** 点“生成绑定码”，或者运行：

```bash
python -m scripts.pair --feishu
```

会得到一条“绑定 123456”。把这条消息私聊发给机器人即可。绑定码 5 分钟内有效，只能用一次。

## 在飞书里能做什么

- 所有查询和对话都可以直接在飞书完成。
- **黄色**操作：在飞书卡片上点确认。
- **红色**操作：飞书里不能输入验证码，机器人会给一个链接，在 TRUSTA 网页里打开同一个会话完成验证。这个链接使用你在[访问方式](#/setup)里设置的地址（局域网或隧道），所以手机也能打开。

## Webhook 模式

如果你已经有公网地址，也可以选 `webhook` 模式：飞书把事件推送到 `POST /api/channels/feishu/webhook`。需要额外填写 Verification Token，以及可选的 Encrypt Key。
